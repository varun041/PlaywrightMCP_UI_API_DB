# Failed Playwright Test Execution — Analysis Instructions

When a Playwright test fails, perform the following analysis.

## Inspect

- Playwright Trace
- Video
- Screenshot
- Console Logs
- Network
- API Responses
- Database Results

## Generate

- Root Cause
- Failure Category
- Suggested Fix
- Confidence Score
- Automation Issue
- Application Issue
- Infrastructure Issue
- Flaky Score
- Recommended Action

Resolve the failures
